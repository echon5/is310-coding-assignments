### Comparing the Wikipedia and Metropolitan Museum of Art APIs

For this assignment, I used Wikipedia's MediaWiki Action API and the Metropolitan Museum of Art API to look at information about Vincent van Gogh. I chose the Met Museum API because I was interested in seeing how a museum's information about an artist compares to Wikipedia. Neither API required an account or an API key, but Wikipedia expects users to include a descriptive User-Agent. Both APIs also have rate limits, with the Met allowing up to 80 requests per second and Wikipedia having its own limits to prevent excessive use. Both APIs returned JSON data, but the information was organized differently. Wikipedia gave me a long biography about Van Gogh, while the Met first gave me a list of artwork IDs that I had to look up separately to get more details. Through the Met API, I found The Zouave, which is one of Van Gogh's artworks. Another difference is that Wikipedia is run by the nonprofit Wikimedia Foundation and relies mostly on donations, while the Met API is maintained by the museum to share information about its collection. However, both APIs have limitations in what they include. Wikipedia depends on what people choose to write about, while the Met only includes artworks that are part of its collection. This means that famous Western artists like Van Gogh may have much more information available compared to lesser-known artists from other cultures. Overall, this assignment helped me understand that even though APIs make information easier to access, the data they provide is still influenced by the organizations and people who create and maintain it. I also ran into an issue when the Met's original API endpoint no longer worked, which showed me how changes to an API can affect someone's ability to access data.
